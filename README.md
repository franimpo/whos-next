# Who's Next?

A dark-humoured anonymous prediction game built with Next.js, Supabase and Wikidata.

## Included

- Famous-person autocomplete backed by Wikidata
- Canonical Wikidata IDs to prevent duplicate/misspelled candidates
- Anonymous one-vote-per-browser-per-round voting (the vote can be changed)
- Live public leaderboard with totals and percentages
- Dark/sinister visual theme
- Admin control room to close a round and record the actual date of death
- Previous-departure highlight
- Historical archive with date of death, final rank, votes and percentage
- Server-side Supabase access with RLS enabled

See `INSTALL.md` for setup and deployment instructions.
